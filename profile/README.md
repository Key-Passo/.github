## 📌 Sobre o Projeto

O **Key-Passo** é um projeto acadêmico desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)** por uma equipe formada por **5 estudantes**.

O projeto utiliza principalmente:
- ![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white) **Java**
- ![Java Swing](https://img.shields.io/badge/Java_Swing-007396?style=flat-square&logo=java&logoColor=white) **Java Swing**
- ![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) **MySQL**
- ![JDBC](https://img.shields.io/badge/JDBC-007396?style=flat-square&logo=java&logoColor=white) **JDBC**
- ![POO](https://img.shields.io/badge/POO-Conceito-FFC72C?style=flat-square&labelColor=002B49) **Programação Orientada a Objetos**
- ![Git](https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white) **Git**
- ![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white) **GitHub**
- ![Eclipse](https://img.shields.io/badge/Eclipse-2C2255?style=flat-square&logo=eclipseide&logoColor=white) **Eclipse**

O Key-Passo busca demonstrar a aplicação prática de:
- Programação Orientada a Objetos;
- Desenvolvimento de interfaces gráficas;
- Banco de dados;
- Operações CRUD;
- Integração entre Java e MySQL;
- Controle de versões;
- Trabalho colaborativo.

## 🚀 Objetivo do Projeto

O principal objetivo do **Key-Passo** é desenvolver uma aplicação que reúna diferentes ferramentas de acesso e organização de informações em um único sistema.

A proposta é transformar os conhecimentos estudados na disciplina de **Programação Orientada a Objetos (POO)** em uma aplicação prática e que tenha uma possível utilização no cotidiano, funcionando como uma ferramenta completa de organização pessoal.

> 💡 **Nota:** O objetivo do projeto não é simplesmente criar três exercícios separados, mas sim desenvolver módulos coesos que façam parte de uma proposta unificada de sistema.

## 🎯 Objetivos

### Objetivo Geral
Desenvolver um sistema unificado em Java com interface gráfica Swing e banco de dados MySQL que integre controle de acesso, gestão de contatos e registro de anotações, aplicando os pilares da Programação Orientada a Objetos em uma solução voltada para a organização pessoal do cotidiano.

### Objetivos Específicos
- Aplicar POO na prática
- Desenvolver interfaces gráficas com Java Swing
- Criar sistema de autenticação
- Desenvolver gerenciamento de contatos
- Desenvolver agenda de anotações
- Trabalhar com MySQL
- Utilizar JDBC
- Aplicar CRUD
- Utilizar Git e GitHub
- Desenvolver colaborativamente
- Relacionar teoria e prática

---

## 🌟 Para que o Key-Passo pode ser usado?

O **Key-Passo** pode ser utilizado como uma ferramenta de organização pessoal, reunindo a gestão de contatos e anotações em um mesmo sistema centralizado. A proposta é oferecer praticidade ao usuário para gerenciar suas redes de contatos e registros diários através de funcionalidades planejadas e integradas.
